# 📱 Mobile Sales Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing mobile sales data using Microsoft Power BI. An interactive dashboard was developed to monitor sales performance, identify trends, and generate meaningful business insights.

## 🎯 Project Objectives
- Analyze overall mobile sales performance.
- Track total revenue and quantity sold.
- Identify top-performing mobile brands and models.
- Analyze customer purchasing patterns.
- Understand sales trends across different cities and time periods.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Features
- Interactive KPI cards
- Sales and revenue analysis
- Brand and mobile model performance
- Payment method analysis
- Monthly sales trends
- Interactive slicers and filters
